# Google Play Store Data Analysis

## Project Overview

This project focuses on analyzing Google Play Store application data to understand app ratings, reviews, installations, categories, pricing, and user sentiment. The project was completed as part of my Data Analytics internship.

## Objectives

- Analyze application ratings and reviews
- Study app installation patterns
- Compare different app categories
- Analyze free and paid applications
- Examine user review sentiment
- Identify useful patterns and insights from the available data

## Datasets

The project uses two cleaned datasets:

1. Google Play Store Application Dataset
2. Google Play Store User Reviews Dataset

## Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook
- GitHub

## Data Cleaning & Preprocessing

The datasets were cleaned and prepared for analysis by handling missing values, removing duplicate records, converting data types, processing installation and size values, and preparing relevant analytical columns.

## Analysis & Visualization

The project includes exploratory data analysis and visualizations to understand:

- App categories
- Ratings
- Reviews
- Installations
- App size
- Pricing
- User sentiment
- Relationships between different application attributes

## Project Limitation

A geographical/Choropleth map could not be completed because the available Google Play Store dataset does not contain country or geographical location information. Therefore, no geographical values were assumed or artificially added.

## Project Files

- `Google Play Store Project (1).ipynb` – Python analysis and visualizations
- `Googleplaystore_app_cleaned.csv` – Cleaned application dataset
- `googleplaystore_review_cleaned.csv` – Cleaned user review dataset

## Conclusion

The analysis provides useful insights into Google Play Store applications based on ratings, reviews, installations, categories, pricing, and user sentiment. The project demonstrates practical skills in data cleaning, exploratory data analysis, visualization, and interpretation using Python.
