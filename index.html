About the Project

Google Play Store Data Analysis

The project focuses on analyzing Google Play Store application data to understand application categories, ratings, reviews, installations, size, pricing and other application attributes.

Python was used for data cleaning, preprocessing, exploratory data analysis and visualization. Power BI was used to present analytical findings through interactive visualizations.

Project Objectives

Key questions addressed during the analysis

  • Identify application categories with the highest number of installations.
  • Analyze application rating patterns.
  • Study installation trends over time.
  • Analyze the relationship between installations and user reviews.
  • Compare ratings, reviews, application size and installations to understand application performance.
  • Create visualizations to communicate important patterns and analytical findings.
